## 二、方法归纳与核心思想

### 2.1 排序类方法

- **Unbiased / Identifiable Learning to Rank**  
  在点击/曝光偏差下做无偏排序估计（Identifiability Matters）。  
  **漏洞情报启示**：漏洞情报来源多样、标注有偏（如仅已披露漏洞），可借鉴“可识别性条件 + 无偏估计”对**未观测/未知漏洞**的排序更稳健。

- **Ranking with Uncertain Predictions**  
  在预测不确定时保证排序的稳定性与多群体公平（Stability and Multigroup Fairness in Ranking with Uncertain Predictions）。  
  **漏洞情报启示**：漏洞严重性/影响范围本身不确定，需要**在不确定性下做排序**并控制误报/漏报的公平性与稳定性。

- **Listwise / Pairwise 范式**  
  Listwise（LIST T5、FIRST、LIRE）、Pairwise（PRP-Graph、Pairwise Ranking for NER）等。  
  **漏洞情报启示**：对漏洞情报条目做**列表级排序**（整体优先级）或**成对比较**（两两谁更应优先处置），可结合 LLM 做 listwise rerank 或 pairwise prompt。

- **Learning to Rank for OOD / 异常**  
  SELFOOD：用 Learning to Rank 做分布外检测（Self-Supervised OOD via Learning to Rank）。  
  **漏洞情报启示**：把“是否为未知/新型漏洞”视为一种序关系或排序任务，用 L2R 区分已知 vs 未知模式，辅助**未知漏洞发现与排序**。

- **Sorting with Predictions**（NeurIPS）、**Sorting and Hypergraph Orientation under Uncertainty with Predictions**（IJCAI）  
  利用（可能出错的）预测来加速排序/图定向，并给出在预测质量差时的性能保证。  
  **漏洞情报启示**：用粗粒度模型（如风险分数）做“预测”，再在有限预算下对高优先级项做精细排序或人工复核，适合**资源受限下的漏洞优先级排序**。

- **Conformal Prediction via Label Ranking**  
  用标签排序形式做 conformal prediction，得到带保证的预测集。  
  **漏洞情报启示**：对漏洞类型/严重性做**带置信度或集合预测**的排序，便于“高置信优先处置、低置信观察”的预警策略。

### 2.2 预警/预测/风险/异常类方法

- **Conformal Prediction / Risk Control**  
  Conformal Prediction、Conformal Risk Control、Non-Exchangeable Conformal Risk Control、Provably Robust Conformal Prediction 等，在有限样本下给出误报率/漏报率控制。  
  **漏洞情报启示**：对“是否需预警”或“风险等级”做**校准与可控错误率**的预测，满足预警系统对误报率/漏报率的可解释要求。

- **时序预测 + 多步 horizon**  
  事故预见（Accident Anticipation via Temporal Occurrence Prediction）将目标从“当前帧风险”改为**多未来时间步的分数**（如 0.1s–2.0s），并用 TTA/FAR 约束评估。  
  **漏洞情报启示**：未知漏洞预警可定义为**“未来某时间段内披露/爆发概率”**，采用多步预测 + 时间窗口内的召回/误报约束（类似 TTA+FAR）设计指标。

- **Credal / 不确定性预测**  
  Credal Prediction（相对似然、认识不确定性）、Uncertainty Quantification、Selective Prediction。  
  **漏洞情报启示**：对新型漏洞或少样本漏洞类别，显式建模**认识不确定性**，在不确定高时触发“人工复核”或“观察期”，实现**选择性预警**。

- **Contamination-Resilient Anomaly Detection**  
  在部分观测的正常/异常数据上做对抗式学习，提升对污染的鲁棒性。  
  **漏洞情报启示**：漏洞情报流中常有噪声、误标、敌意注入，需要**抗污染异常检测**，避免将脏数据当“新型漏洞”误报。

- **Graph / 动态图异常**  
  Beyond Homophily: Robust Graph Anomaly Detection; SAD: Semi-Supervised Anomaly Detection on Dynamic Graphs。  
  **漏洞情报启示**：把组件/依赖/版本建成图，**图上的异常或演化模式**可作为未知漏洞或供应链风险的预警信号。

- **Code Vulnerability Detection（ACL）**  
  Generalization-Enhanced Code Vulnerability Detection via Multi-Task Instruction Fine-Tuning。  
  **漏洞情报启示**：用多任务 + 指令微调提升**泛化到未见漏洞类型**的能力，与“未知漏洞”直接相关，可和排序、预警管线结合。

## 三、面向未知漏洞情报预警的提炼思路

### 3.1 排序侧

1. **无偏/可识别的漏洞优先级排序**  
   借鉴 Unbiased L2R 与 identifiability：在存在披露偏差、标注缺失的情况下，估计“真实风险序”并给出可识别条件，用于**未知或未充分观测漏洞**的排序。

2. **不确定预测下的稳健排序**  
   借鉴 Ranking with Uncertain Predictions：对漏洞严重性/影响范围建模不确定性，在满足稳定性与多群体（如不同资产类型）公平下做排序，避免因模型不确定而频繁调序。

3. **Listwise / Pairwise + LLM**  
   用 Listwise Reranking（如 ListT5、FIRST）或 Pairwise Ranking Prompt（如 PRP-Graph）对候选漏洞情报列表重排；在预算有限时用 EcoRank 类**预算约束重排序**，优先把调用留给高价值条目。

4. **Learning to Rank 用于“未知 vs 已知”**  
   借鉴 SELFOOD：将“更像未知漏洞”定义为排序目标，用 L2R 学习区分已知漏洞模式与新型模式，输出**未知漏洞嫌疑度排序**，供二次确认或预警触发。

5. **Sorting with Predictions 式两阶段**  
   第一阶段用轻量预测（如风险分数）做粗筛；第二阶段对 top-k 做精细排序或人工复核，并理论/实验上保证在预测质量差时仍可接受（learning-augmented algorithms 思路）。

### 3.2 预警侧

1. **Conformal / Risk Control 控制误报与漏报**  
   对“是否预警”“风险等级”做 Conformal Prediction 或 Risk Control，在指定置信水平下控制误报率或漏报率，使预警可解释、可配置。

2. **多步时间窗 + TTA/FAR 式评估**  
   将预警目标设为“未来 Δt 内是否出现/披露”，用多步预测 + 时间窗内召回与误报约束（类似事故预见中的 TTA+FAR）设计指标与阈值，便于运营落地。

3. **选择性预警与不确定性**  
   结合 Credal Prediction、Uncertainty Quantification、Selective Prediction：高不确定性时**弃权或进入观察队列**，低不确定性时触发正式预警，实现“宁可晚报、不可错报”的策略。

4. **抗污染的异常检测**  
   在情报流中显式处理标注错误、对抗注入，采用 Contamination-Resilient 或鲁棒图异常方法，减少将噪声当未知漏洞的误报。

5. **图与动态图上的漏洞/供应链风险**  
   用依赖图、资产图、版本演化图做**图异常检测**，将“子图/演化异常”作为未知漏洞或供应链风险的早期信号，再接入排序与 Conformal 预警。

6. **代码漏洞泛化 + 多任务指令**  
   沿用 Generalization-Enhanced Code Vulnerability Detection 思路，用多任务与指令微调提升对**未见漏洞类型**的检测与排序，再与上述排序、预警模块串联。

### 3.3 系统层面

- **排序与预警一体化**：先对情报条目做排序（含“未知嫌疑度”），再对 top 条目做 Conformal/多步预测/选择性预警，形成“排序 → 预警阈值 → 动作”的流水线。  
- **数据与评估**：针对披露偏差、少样本未知类型、污染标注设计评估协议（如无偏 L2R 评估、TTA+FAR、Conformal 覆盖率），与现有漏洞数据集（如 Security 目录下的 vuln 相关论文）结合使用。

## 四、可直接复用的技术关键词

- **排序**：Unbiased Learning to Rank, Listwise / Pairwise Reranking, Ranking with Uncertain Predictions, Sorting with Predictions, Label Ranking, Learning to Rank for OOD  
- **预警/风险**：Conformal Prediction, Conformal Risk Control, Credal Prediction, Uncertainty Quantification, Selective Prediction, Risk-Sensitive  
- **异常**：Contamination-Resilient Anomaly Detection, Graph Anomaly Detection, Semi-Supervised Anomaly on Dynamic Graphs, OOD detection via Learning to Rank  
- **时序**：Multi-horizon forecasting, TTA/FAR evaluation, Conformalized time series, Temporal occurrence prediction  
- **漏洞**：Code vulnerability detection, Multi-task instruction fine-tuning, Generalization to unseen vulnerability types
